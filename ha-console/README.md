# Hyper Clock HA Console

移动优先的 Home Assistant 控制界面组件包。它不保存令牌、不连接 HA，也不实现独立鉴权；所有数据和操作通过 `back-stage` 的同源受保护 API 完成。

同一组件用于两个入口：

- `/ha`：手机、平板和电脑的轻量独立入口。
- `/admin/ha-control`：总后台侧边栏中的嵌入入口。

支持房间、在线状态、收藏与文本筛选，灯光/开关控制、亮度调整、场景、自动化、传感器和摄像头代理。页面最多同时订阅 80 个当前可见实体，切换筛选时释放旧订阅；后端复用全局 HA 连接。

扩展新设备类型时，在 `src/ui/ha-console.tsx` 的 `domainMeta` 增加图标和标签，并在设备详情中增加领域专属控件。后端服务白名单仍需单独明确放行。
