# Hyper Clock · watch-face

Q775 本机 Chromium Kiosk 专用表盘。该目录只负责显示和物理功能键交互，不包含管理后台、用户系统或 HA Token。

## 数据边界

- `back-stage` 通过仅供本机表盘使用的只读 SSE 提供完整 HA 状态、区域/设备/实体树、天气预报、表盘配置和唤醒事件。
- 主页面右侧常驻天气、日期/日历、课程、设备和媒体卡片；简报、备忘与缓存提示在动态卡片中轮播。
- 第二屏使用 HA `weather.get_forecasts` 展示实时指标、逐小时预报、未来一周与日出日落；已原生适配 HACS 和风天气（QWeather API v7）的 `weather.he_feng_tian_qi` 与 `sensor.he_feng_tian_qi_*` 实体，包括温湿度、体感、风、气压、能见度、紫外线、AQI、PM2.5/PM10、O₃ 等。第三屏按 HA 区域自动组织全部 Registry 设备，并可切换查看 HA 原生集成目录，无需逐台填写实体。
- 原生集成目录聚合 HA 配置项、设备/实体注册表与服务动作，因此无硬件设备的版本、时间日期、工作日、季节、TTS、Radio Browser、购物清单等集成也不会被漏掉。
- HA Companion App（`mobile_app`）设备会被提升到个人设备轨道：电量取 `*_battery_level`，充电状态取 `*_battery_state` / `*_is_charging`，App 离线时回退到 `device_tracker` 的电量属性；首页设备卡同步显示，无有效电量数据时回退为全屋设备摘要。
- 优先使用 HA `sun.sun` 的日出/日落状态切换晨光、白昼、暮色和夜间主题，离线时按配置时区自动兜底。
- 设备开关和背光操作先发送到本目录的 `/api/control` BFF，再携带服务端共享密钥转发到 `back-stage`；密钥不会进入浏览器。
- 控制面暂时离线时使用 `data/default-config.json` 启动，本地时钟继续运行。
- 后台把最近一次 HA 实体快照缓存到磁盘，表盘同时缓存到浏览器；HA 或后台断线时自动显示最近数据并明确标记“缓存”。
- 默认配置不包含示例实体或演示内容，所有业务卡片都来自真实 HA 数据；日历、课程、简报和备忘仍可在后台选择重点实体。

## 按键

- Win / 音量加短按：下一页；音量减：上一页。
- Win 长按：完整/极简切换；语音启用后普通长按发出语音事件，超长按切换极简。
- 语音启用时，长按 Win 会显示全屏聆听反馈，并在 8 秒后自动退出；再次触摸可立即关闭。
- 任意功能键从极简/熄屏回到完整模式。
- 可在页面非交互区域左右滑动切页；手势先锁定方向，达到 64px 距离或速度阈值才切换，首尾页面提供阻尼回弹。
- 设备列表、天气预报、课表、日历和股票列表等可滚动区域不会触发表盘翻页。
- 极简模式使用 OLED 纯黑 `#000000` 背景和低亮时分秒，不绘制渐变、纹理、光晕与阴影；进入熄屏状态后页面完全黑屏。
- 电源键不进入网页，归 Linux systemd-logind/udev。

阈值全部由 `/admin/rules-config` 修改。表盘每 30 秒向后台上报模式和页面，HA 触发器可以唤醒到完整或极简模式。

## 动画性能

- 翻页拖动按动画帧合并更新，松手后使用统一的弹性缓动归位。
- 主时钟秒盘采用机械表式 60 刻度、扫秒指针与配重结构；指针以合成层 60 秒线性旋转，数字秒数仍保持精确读数，切换页面后也会维持正确相位。
- 首页天气和日出日落场景在 HUD 安全区内视觉居中，使用交叉淡化与渐隐遮罩过渡，不进行瞬时替换或硬边裁切。
- 首页与天气详情页共用自适应矢量天气资产：太阳、月亮、云层按当前明暗主题切换轮廓和阴影，日照地景通过 SVG 遮罩向四周渐隐；每个图形实例使用独立渐变与遮罩 ID，避免多页面同时渲染时串色。
- 非当前页面暂停 CSS 动画；语音波形、天气和环境光效优先使用 `transform`/`opacity`，避免持续触发布局。
- 系统启用“减少动态效果”时，所有动画自动降级。

## 响应式排版

- 根字号会同时参考视口宽度和高度缩放；页面标题、行情价格、系统指标与传感器读数另设安全上下限。
- 主时钟列使用“状态—时钟—页脚”三段式弹性网格；时分字号、秒盘和日期按左栏容器宽度缩放，后台的时钟比例设置会参与真实排版，不再以视觉变换挤压相邻内容。
- 首页天气 HUD、日历、课表和个人设备统一提高最小字号；天气纵向指标同步扩宽安全栏并为动画预留独立区域，卡片高光位于文字层后方，长内容继续使用单行省略而不会覆盖相邻数据。
- 和风天气采用字段级自动发现：有效的 `sensor.he_feng_tian_qi_*` 值优先；单个实体缺失、`unknown` 或 `unavailable` 时，仅该字段回退到后台原先配置的 `weather.*` 属性。和风不提供逐小时或逐日预报时，后台自动改用原天气实体的预报，不影响其余和风实时数据。
- 个人设备使用同一套响应式电量环：绿色表示正常、琥珀表示偏低、红色表示临界，环内显示设备类型与百分比，旁侧小徽标显示充电和在家/离家/同步状态。
- 首页右栏使用带内容下限的 `minmax()` 行轨道，天气、日历、课表、设备、媒体和动态卡片不会被纯比例网格压到文字高度以下。
- 天气、设备、传感器、课程、日历、系统和股票页统一采用“标题区 + `minmax(0, 1fr)` 内容区”；列表空间不足时在卡片内部滚动，不裁切到相邻容器。
- 长实体名、媒体信息、课程地点和数值会根据语义换行或显示省略号，图标保持固定尺寸，不会挤压文字。

## 运行

开发：复制 `.env.example` 为 `.env`，设置控制面地址与共享密钥，然后使用 Node.js 24 LTS：

```bash
npm install
npm run dev        # http://127.0.0.1:3000，需要 back-stage 同时运行在 3001
```

生产：在 Q775 上用仓库根目录的 `sudo scripts/deploy.sh && sudo scripts/launch.sh`（原生 systemd，推荐），详见 [`docs/linux-deployment.md`](../docs/linux-deployment.md)；也可以用 `docker compose up -d --build`。

`next build` 以仓库根目录为追踪根，独立服务器输出在 `.next/standalone/watch-face/server.js`，`npm start`（`scripts/start.mjs`）会自动定位并复制静态资源。
